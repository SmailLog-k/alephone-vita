# Изменения порта для PS Vita

Этот документ описывает основную инженерную работу, выполненную специально для PlayStation Vita в Aleph One Vita.

## Платформенный слой

Новые специфичные для Vita файлы находятся в:

```text
VitaPlatform/
```

Они обеспечивают:

- интеграцию запуска и завершения работы Vita;
- обработку путей Vita;
- раскладку управления Vita;
- настройки производительности Vita;
- специфичную для Vita настройку SDL/окружения;
- звуковой и платформенный glue-код, необходимый текущей сборке;
- обработку текста с кириллицей, используемую необязательной русской локализацией.

## Сборка и упаковка

Добавлены:

```text
build-vita-vpk.sh
vita-crt/
```

Процесс сборки компилирует движок, создаёт Vita `eboot.bin`, генерирует `param.sfo` и упаковывает профильные VPK.

Результаты:

```text
pkg/eboot.bin
pkg/alephone_vita_legacy.vpk
pkg/alephone_vita_marathon2.vpk
pkg/alephone_vita_infinity.vpk
```

Одна общая кодовая база движка создаёт несколько отдельных приложений LiveArea через манифесты Vita-профилей. Каждый профиль может определять собственные Title ID, имя приложения, настройки, сохранения, быстрые сохранения, журналы, каталог данных, оформление, ресурсы руководства и поведение совместимости.

Текущие VPK релиза:

```text
alephone_vita_legacy.vpk     -> Marathon
alephone_vita_marathon2.vpk  -> Marathon 2
alephone_vita_infinity.vpk   -> Marathon Infinity
```

Текущая модель релиза — прямая установка трёх отдельных игровых VPK через VitaShell.

## Рендеринг и производительность

Рендерер Vita был адаптирован под характеристики производительности консоли.

- Полноэкранный широкоформатный вывод 960x544.
- Программный рендерер используется как поддерживаемый путь рендеринга Vita.
- Настольный путь OpenGL в текущем Vita-релизе не используется.
- Настольный Lua/Enhanced HUD заменён оптимизированным для Vita классическим HUD/cockpit, поскольку Lua HUD вызывал серьёзные скачки времени кадра на Vita.
- Классический игровой HUD сохранён без постоянных просадок производительности, наблюдавшихся в ранних сборках.
- Исходный постоянный эффект затенения жидкостей заменён лёгким Vita-оверлеем на финальном этапе вывода кадра.
- Ранее выявленная постоянная просадка частоты кадров при полном погружении устранена в текущем протестированном пути.
- Для изменений cockpit/HUD Marathon используются обновления «грязных прямоугольников», поэтому весь HUD не требуется масштабировать каждый кадр.
- Карта, терминалы, меню и полноэкранные переходы адаптированы под Vita.
- Запросы перерисовки HUD подавляются при открытой непрозрачной карте, чтобы исключить однокадровые вспышки спрайтов HUD во время управления картой.
- После выхода из карты/терминала Marathon принудительно полностью перерисовывает cockpit, чтобы обновления «грязных прямоугольников» не оставляли устаревшие чёрные области экрана.
- Для вступительной/меню-музыки используется fallback на распространённые имена потоковых музыкальных файлов, например `Music.ogg`, если исходный файл `Music` отсутствует.
- Используются специфичные для Vita настройки производительности по умолчанию.
- Оверлей FPS и запись журналов производительности включаются только диагностическими флагами сборки.
- Инструменты профилирования/FPS остаются доступными для диагностических сборок, но не активируются в обычном релизе.

## Управление

Кнопки и стики Vita напрямую сопоставлены игровым действиям Aleph One.

Текущая пользовательская раскладка:

| Элемент Vita | Действие |
| --- | --- |
| Левый стик | Передвижение |
| Правый стик | Поворот / обзор |
| R | Основной огонь |
| L | Дополнительный огонь |
| Cross | Действие / использовать |
| Circle | Бег |
| Square | Карта |
| Triangle | Центрирование камеры |
| D-pad | Оружие / инвентарь / управление картой |
| Start | Выход из текущей игры в главное меню с подтверждением |

Дополнительные исправления ввода Vita:

- Порог аналоговой оси скорректирован так, чтобы движение вперёд/назад надёжно работало на реальном устройстве.
- При открытой карте D-pad вверх/вниз зарезервирован для масштабирования карты и больше не переключает оружие одновременно.

## Игровой процесс, HUD и меню

Текущее отображение игры на Vita представляет собой отдельную консольную адаптацию классических путей рендеринга Aleph One.

- Классический HUD/cockpit интегрирован в программный рендерер Vita.
- HUD/cockpit Marathon использовался на протяжении полного прохождения кампании от начала до конца на реальном устройстве.
- HUD, карта, терминалы и меню Marathon 2 и Marathon Infinity играбельны и проверялись через прямую загрузку уровней.
- Marathon 2 и Marathon Infinity используют Vita-оверлей выбора в меню для надёжной визуальной обратной связи.
- Встроенный выбор уровня открывается из главного меню сочетанием `L + R + Cross`.
- Выбор уровня полезен для повторного прохождения и точечного регрессионного тестирования, включая дополнительные карты, присутствующие в данных сценария.

## Интеграция LiveArea

Три отдельных игровых профиля включают собственные ресурсы оформления Vita.

- Отдельные пузыри LiveArea для Marathon, Marathon 2 и Marathon Infinity.
- Собственные иконки и оформление LiveArea для каждой игры.
- Встроенные руководства LiveArea для всех трёх игр.
- Английские и русские страницы руководства по установке, управлению, настройке перевода, устранению неполадок и юридической информации/авторству.

## Поддержка кириллицы и русского перевода

В движок Vita добавлена поддержка отображения кириллицы.

Для всех трёх профилей трилогии Marathon поддерживаются необязательные слои русского перевода. Предоставленный перевод охватывает все сюжетные тексты терминалов.

Слой перевода распространяется отдельно от VPK движка и не заменяет оригинальные данные сценария. Пользователь по-прежнему предоставляет оригинальные игровые данные и копирует необязательную папку `Russian/` в соответствующий каталог игровых данных.
